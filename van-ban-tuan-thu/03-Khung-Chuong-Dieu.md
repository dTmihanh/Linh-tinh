# Khung Chương – Điều Quy chế Tuân thủ (đối chiếu nhanh)

| Chương | Điều | Tên Điều |
|--------|------|----------|
| I. Quy định chung | 1 | Phạm vi điều chỉnh |
| | 2 | Đối tượng áp dụng |
| | 3 | Giải thích từ ngữ |
| | 4 | Mục tiêu của công tác tuân thủ |
| | 5 | Nguyên tắc công tác tuân thủ |
| | 6 | Quan hệ với Quy định Pháp chế và văn bản nội bộ khác |
| II. Tổ chức hệ thống tuân thủ | 7 | Mô hình tổ chức tuân thủ (2 tuyến nội bộ) |
| | 8 | Trách nhiệm của Chủ tịch công ty, Giám đốc và Ban Giám đốc |
| | 9 | Trách nhiệm của Pháp chế (đầu mối tuân thủ) |
| | 10 | Trách nhiệm của các Phòng, Ban, Phân xưởng |
| | 11 | Trách nhiệm của người lao động |
| III. Nội dung và lĩnh vực tuân thủ | 12 | Nhóm nghĩa vụ tuân thủ chung |
| | 13 | Các lĩnh vực tuân thủ trọng yếu |
| | 14 | Danh mục văn bản, nghĩa vụ áp dụng |
| | 15 | Yêu cầu đặc thù DNNN đồng thời là DN quân đội |
| IV. Quy trình quản lý tuân thủ | 16 | Nhận diện và đánh giá rủi ro tuân thủ |
| | 17 | Cập nhật pháp luật và điều chỉnh nội bộ |
| | 18 | Kiểm soát tuân thủ trong hoạt động thường xuyên |
| | 19 | Giám sát, kiểm tra tuân thủ nội bộ |
| | 20 | Báo cáo tuân thủ |
| | 21 | Xử lý vi phạm và khắc phục |
| | 22 | Phổ biến, đào tạo và xây dựng văn hóa tuân thủ |
| V. Báo cáo, phản ánh | 23 | Kênh báo cáo rủi ro, vi phạm tuân thủ |
| | 24 | Tiếp nhận, xác minh và phản hồi |
| | 25 | Bảo vệ người báo cáo thiện chí |
| VI. Phối hợp, hồ sơ, bảo đảm | 26 | Phối hợp liên phòng và với cơ quan bên ngoài |
| | 27 | Quản lý hồ sơ tuân thủ |
| | 28 | Nguồn lực và điều kiện bảo đảm |
| VII. Tổ chức thực hiện | 29 | Khen thưởng |
| | 30 | Xử lý vi phạm Quy chế |
| | 31 | Sửa đổi, bổ sung |
| | 32 | Hiệu lực thi hành |
| Phụ lục | PL1 | Ma trận phân công tuân thủ theo lĩnh vực |
| | PL2 | Mẫu Báo cáo tuân thủ định kỳ |
| | PL3 | Mẫu Phiếu nhận diện / đánh giá rủi ro tuân thủ |
| | PL4 | Mẫu Báo cáo sự vụ / phản ánh vi phạm tuân thủ |
| | PL5 | Khung danh mục văn bản, nghĩa vụ áp dụng |
